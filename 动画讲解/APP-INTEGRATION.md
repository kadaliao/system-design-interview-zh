# 动画讲解接入 App：方案草案（未实施，没有改任何 App 代码）

更新：2026-10-01。依据：本目录 28 支视频的压缩实测、三家国内 CDN 与 Cloudflare 的官网价格、中国发布合规的官方原文（来源见各节）。价格和政策会变，落地前请回官网核对。

## 0. 已确定的前提

| 项 | 决定 |
|---|---|
| 语言 | 只有中文（zh）和英语（en）。**英语视频还没有做**，见第 8 节 |
| 选源 | 中国大陆地区走国内 CDN；其他地区走 Cloudflare R2。**按用户所在地区选源，不按语言选**，两个源都放两种语言 |
| 观看权限 | 付费用户才能看；免费用户可免费使用第 1 章，并可免费看第 1 章的视频 |
| 视频格式 | H.264 720p、音频 mono AAC 64k、faststart 的 MP4，CRF 28（VMAF 95.3）。**28 支实测合计 128.4 MB / 103.1 分钟**（每支 2.93 到 5.65 MB），文件在 `动画讲解/dist/v1/zh/`，已逐支生成 sha256 清单 |

**一个必须先定的前提：付费模式。** 现在 App Store Connect 里是「先付费下载」¥88。要让「免费用户可用第 1 章」，下载必须是免费的，再用一次性内购（非消耗型）解锁全部章节。这是定价模式的改动，不只是视频的事，也影响第 8 节的合规判断。如果仍保持先付费，就没有「免费用户」，免费视频只能是网站上的公开试看。

## 1. 总体架构

```
App ──(StoreKit 2 交易凭证)──▶ 签发服务 ──▶ 短时效签名 token
 │                              ├─ 中国大陆：国内云函数（备案域名）
 │                              └─ 其他地区：Cloudflare Worker
 └──(视频地址 + token)──▶ 视频源
                          ├─ 中国大陆：国内 CDN（备案域名，URL 鉴权）
                          └─ 其他地区：R2 + 自定义域名（Worker 校验 token）
```

- 视频本身是静态文件，真正需要「会判断谁付了钱」的只有一个很小的签发服务。
- 为什么两个地区各放一个签发服务，而不是共用一个：把海外用户的购买凭证发到大陆服务器、或反过来，都会引入跨境数据传输的合规问题；而且大陆访问 workers.dev 或 Cloudflare 自定义域名的稳定性，官方文档没有保证，我也没实测。两个服务代码相同，只是部署位置和 token 格式不同。

## 2. 地区与语言选源

- 地区判断用 StoreKit 的 `Storefront.current`，国家码为 `CHN` 走国内源，其余走 R2。不要只看设备语言或系统地区，用户可以是在海外使用中文。
- 语言跟随用户在 App 里选的内容语言（zh / en），和地区无关，所以大陆用户也能看英文视频。
- 两个源的目录结构一致：`/v1/{lang}/chNN.mp4` 和 `/v1/{lang}/manifest.json`，文件名带版本号 `v1`，设长缓存，更新内容时发布 `v2`，不覆盖旧文件。
- 域名换了或被封需要发版才能改：建议另放一个极小的远程配置（只含两个源的基础地址），App 启动时拉取，失败回落到内置地址。

## 3. 付费门控（核心）

**流程：**
1. App 点开视频时，若该章免费（第 1 章），直接用公开地址播放，不带 token。
2. 否则取 `Transaction.currentEntitlements` 里「完整版」的签名凭证（JWS），发给对应地区的签发服务。
3. 签发服务验证：Apple 签名证书链、bundleId、productId、环境（沙盒还是正式）、是否被撤销或退款。通过后返回 10 到 15 分钟有效的 token，只对 `/v1/{lang}/` 路径有效。
4. AVPlayer 用带 token 的地址播放，下载缓存用同一个 token。
5. 免费视频放在独立的目录或域名下，不鉴权。各家国内 CDN 的鉴权能不能按目录配置，我没有核实，不行就用两个域名。

**验证凭证用什么：** Apple 官方有 App Store Server 库（Node、Python、Java、Swift），其中的 `SignedDataVerifier` 可以验证签名凭证，需要内置 Apple 根证书；官方 Node 库要求 Node 16+，文档没提 Cloudflare Workers 是否能直接运行，Worker 里可能要用 WebCrypto 自己验证证书链或做兼容，这一点需要先做个原型。来源：[apple/app-store-server-library-node](https://github.com/apple/app-store-server-library-node)。

**签名 token 怎么让视频源认：**
- 海外：R2 前面挂 Cloudflare Worker，校验 token 后再回源。注意 Worker 里用 R2 绑定读取会绕过 CDN 缓存，要主动用缓存 API，否则每次请求都会产生一次 R2 读取操作。
- 大陆：用国内 CDN 自带的 URL 鉴权（时间戳加密钥的签名），由国内云函数生成。

**防住多少：** 这个方案防的是「没付费的人拿到视频地址」。已付费用户把 token 在有效期内转发给别人，仍然可行，但有效期很短，影响有限。如果只想先做最小版本，可以把视频放在不可猜的路径下、由随 App 发布的清单提供地址，不做签发服务；缺点是任何人解开安装包就能拿到全部地址，等于没有门控，需要你自己权衡。

## 4. 播放与本地缓存

见上一轮的方案，要点不变：
- faststart 的 MP4，AVPlayer 直接播远程地址实现秒开，同时用一次整文件下载落盘到 Caches，下次播本地；流量大约翻倍，但每人也就多几分钱。
- 只拉一次的 `AVAssetResourceLoaderDelegate` 代理缓存，等第一版稳定后再做。
- 横屏全屏需要放开 iPhone 横屏，并用 AppDelegate 只对视频页放行。
- 设置页加「视频缓存」小节（占用空间、清除、仅 Wi-Fi 下载）。
- 免费视频缓存后可离线看；付费视频缓存后，是否允许在用户退款或不再有权限后继续播放，需要定一个策略。

## 5. 清单格式

打包脚本 `node lib/pack.mjs zh` 已生成 `dist/v1/zh/manifest.json`（英语做好后用 `node lib/pack.mjs en`）。每支视频记录章节、标题、文件名、时长、字节数和 sha256，App 下载完后用 sha256 校验。`free` 字段（第 1 章为 true）由 `build_app_content.py` 在生成内容包时写入 `course.json`，或单独放一个随包的 `videos.json`，两个做法都可以，倾向后者以免影响现有内容包的生成流程。

## 6. 成本（按每人看完一遍约 0.127 GB）

- **大陆（国内 CDN）：** 1 千人约 ¥27 到 ¥35，1 万人约 ¥266 到 ¥354，10 万人约 ¥2,503 到 ¥3,543（腾讯云最低，七牛按 HTTPS 价最高）。详见上一轮对比。
- **海外（R2）：** 出口流量免费，只有读取操作费；10 种语言也在 10 GB 免费存储内。最坏情形下 10 万用户约 $6 到 $57；加 Worker 签名校验后另加固定约 $5 起每月。本项目只有中英两种语言，存储更小。
- 国内云函数、Worker、对象存储的少量费用没有逐项核实，量级预计很小。

## 7. 中国大陆发布与销售的合规清单

这一节是我查官方原文后的整理，**不是法律意见**，具体以你所在省通信管理局和律师的意见为准。

1. **App 备案（ICP 备案）：** 工信部通知要求在境内从事互联网信息服务的 App 主办者履行备案手续，未备案不得从事 App 互联网信息服务，分发平台也不得为未备案的 App 提供分发（[工信部通知原文](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2023/art_dd783a581c9644a4aee10afa582811db.html)）。Apple 从 2024-04-01 起要求在中国大陆上架的 App 填写备案号，没有备案号的 App 无法提交更新并可能被下架（[App Store Connect 帮助](https://developer.apple.com/help/app-store-connect/reference/app-information/app-information/)，原文写的是「如适用」，具体哪些 App 适用，Apple 页面没有展开）。现在这个 App 基本是离线的，加了视频后会联网提供内容，按通知的字面意思属于要备案的范围。
2. **CDN 域名备案：** 阿里云官方文档要求加速区域包含中国内地的域名必须备案（[文档](https://help.aliyun.com/zh/cdn/add-a-domain-name)）；腾讯云和七牛我没有核实，预计相同。
3. **收费要不要许可证：** 《互联网信息服务管理办法》第三条把「有偿提供信息」定义为经营性，第四条规定经营性实行许可制度、非经营性实行备案制度（[国务院令第 292 号](https://www.gov.cn/gongbao/content/2000/content_60531.htm)）。按字面，收费提供视频课程更接近经营性，需要增值电信业务经营许可证（ICP 证），一般要求企业主体，具体条件我没有核实。App 备案通知本身没有谈许可证问题，实践中个人开发者通过 Apple 内购收费的情况很多，监管如何认定我没有查到权威结论。**这是最大的不确定项，建议备案前先问当地通信管理局或律师。**
4. **教育类前置审批：** 通知里写明，从事新闻、出版、教育、影视、宗教等 App 的主办者，备案时还应提交相关主管部门审核同意的文件。你的内容是成年人的面试自学材料，是否落入「教育」类、需要哪个部门的文件，我没有核实，备案系统选择服务内容时会有提示。
5. **AI 合成语音标识：** 视频旁白是 AI 合成的语音。《人工智能生成合成内容标识办法》自 2025-09-01 起施行，AI 生成合成的文本、图片、音频、视频等要添加显式标识（用户能明显感知）和隐式标识（文件元数据里）（[新华网](https://www.news.cn/politics/20250314/b7a24028f2924b7681e6ed1bfbd8fade/c.html)、[网信办答记者问](https://www.cac.gov.cn/2025-03/14/c_1743654685896173.htm)）。落地建议：视频片头或播放页明确标注「本视频旁白为 AI 合成」，并在服务协议里说明标识方式；元数据标识的具体写法需要看办法的配套标准。
6. **税务与个人信息：** Apple 自 2025 年 7 月起按国务院令第 810 号向税务机关报送中国开发者的身份和交易信息，个人开发者需要提供身份证信息，纳税责任不变（[Apple 说明](https://developer.apple.com/help/app-store-connect/manage-compliance-information/manage-information-for-state-council-decree-no-810/)）。
7. **版权：** README 写明课程整理自 Alex Xu 的书和 liquidslr 的笔记。国内发布、翻译成英文并全球销售，请先确认授权。

## 8. 英语版本要做什么（目前没有）

- 28 个场景里的画面文字是写死在代码里的，需要抽成可按语言切换的文案；旁白脚本要翻译，换英语音色重新合成；每种语言重新渲染（每章约 80 秒，28 章约 40 分钟）。
- 如果 App 本身没有英文版（课程内容、题目、界面），只有视频是英文的意义不大，这个范围需要你定。
- 画面里的英文长度和中文不同，版面需要逐章检查。

## 9. 分阶段落地建议

1. **已完成：** 28 支压成 720p（`dist/v1/zh/`，128.4 MB，含 `manifest.json`）。**待你定：** 付费模式、要不要先做英语版。
2. **原型：** 在真机上抓包，量 AVPlayer 的请求数；做签发服务的原型，验证 Worker 里验证凭证是否可行。
3. **开发：** 清单与缓存模块、播放页、入口、设置、横屏处理；两个地区的签发服务和 CDN 配置。
4. **合规并行推进：** 备案、域名备案、AI 标识，这些耗时较长，建议尽早启动。
