# 架构多巴胺（Arch Rush）

把本仓库的 1039 道练习题做成的网页闯关游戏。玩法框架参考 [grmchn/dopa-drill](https://github.com/grmchn/dopa-drill)（MIT）：每答对一格，画面、音乐和吉祥物就多叠一层；答错只算“差一点”，不扣分、不结束。纯静态、无依赖、无需构建，记录只存在浏览器 localStorage。吉祥物“节点君”、音乐和特效都是为本项目原创的；中英双语，随浏览器语言切换。

```bash
python3 -m http.server 8000      # 在仓库根目录运行，然后打开 http://localhost:8000/game/
node --test game/tests/*.test.mjs
python3 工具/build_game_data.py  # 题库更新后重新生成 game/data（先跑 工具/build_app_content.py）
```

## 玩法

- **格**：单选/判断 1 格；多选每个正确项 1 格；填空每个空 1 格；排序每一项 1 格；配对每一对 1 格。每个被接受的输入加 1 连击。
- **多巴值**：对数曲线，基本问题终点约 10^2.3，连击最高 2 倍；越过 100、1000、1 万……有里程碑。多巴值决定 9 级演出阶段（背景层、BGM 层、节点君装扮）。
- **得分**：基本问题全部完成 100 分；一次答对率 ≥ 80% 可进入加试，第 k 题加 10+5k 分，不设上限。
- **连击时限**：只让连击断掉，不扣分；可在设置里放宽或关闭。答错时音乐暂压低并给“差一点”；同一格连错两次会提示正确项。
- **模式**：我的水平（首次是实力检测，之后自动排新课 + 约 30% 复习）、按章节、练习某一课、复习错题（最多 40 题）、自动演示（不写记录）。
- **技能树**：111 课，章与章有前提。掌握 = 至少 6 题且最近 6 题中 5 题一次答对；之后 ★1–5（★4 需在 ★3 之后隔 7 天）；21 天没一次答对会“生锈”，答对一题擦亮。
- **坚持**：连续天数、登录贴纸（7 天一轮）、补签锤（初始 1，最多 3）、每日 3 个任务（全做完得一把锤）、日历。
- **收集**：290 个成就（含隐藏）、4 种 BGM、6 种皮肤、5 种配色，条件达成即解锁，没有抽奖和付费。

## 代码结构

| 路径 | 内容 |
| --- | --- |
| `js/cells.js` `session.js` `scoring.js` | 题目拆格与判定、一次游玩的状态机、数值曲线（纯函数，有单测） |
| `js/select.js` `skills.js` `progress.js` | 出题、掌握/星级/生锈、结算 |
| `js/streak.js` `quests.js` `trophies.js` `unlocks.js` `growth.js` | 坚持系统、任务、成就、收藏、成长对比 |
| `js/audio.js` `fx.js` `bg.js` `mascot.js` | Web Audio 合成音乐、粒子与背景、吉祥物 SVG |
| `js/ui/` | 各页面 |
| `data/` | 由 `工具/build_game_data.py` 从 iOS 内容包生成的题库（中/英） |
